# Dapur Harian AI — Idea Masakan Setiap Hari

A simple Malay-language recipe suggestion chatbot prototype built with HTML, CSS and JavaScript.

## Features
- Asks for preferred cuisine, available ingredients, budget, meal type, cooking time and dietary preference.
- Suggests a recipe with ingredients, cooking steps, estimated time and approximate cost.
- Includes fallback guidance and a restart option.
- Responsive design for mobile and desktop.

## Run locally
Open `index.html` in a web browser. No installation or API key is needed.

## Publish with GitHub Pages
1. Create a GitHub repository named `dapur-harian-ai`.
2. Upload `index.html` and `README.md` to the repository's root folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then click **Save**.
6. Wait a few minutes and refresh the Pages section. GitHub will show the published website link.

## Important note
This is a rule-based prototype with built-in recipe suggestions. It is not connected to a live AI model or external recipe database. Cost estimates are illustrative and may vary by location and ingredients already available.
